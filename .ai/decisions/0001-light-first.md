# ADR 0001: Light Theme First

## Status
Accepted

## Reason
We need a consistent visual language that aligns with our goal of being a premium, official governance platform.

## Decision
All UI components and layouts must be designed and developed with the Light Theme as the primary experience. Dark Theme is supported but is considered secondary.

## Consequences
Developers must ensure contrast and readability are tested primarily in Light mode. Dark mode overrides should be minimal and deliberate.
