# System Configuration Reference

System configurations are stored in `system_configurations` database table under distinct JSON groups:

- `website_identity`: `community_name`, `logo_url`, `theme_color`.
- `hero_section`: `badge_text`, `title_line1`, `title_line2`, `description`, `primary_cta_text`, `secondary_cta_text`.
- `candidate_section`: `section_title`, `section_description`, `registration_status`, `empty_state_message`, `publication_message`.
- `footer_section`: `copyright_text`, `social_links`, `contact_email`, `contact_phone`.
