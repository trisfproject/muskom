# Permissions Reference

System permissions stored in `permissions` table:

- `system.manage`: Full administrative access to user & role management.
- `audit.view`: Read access to system audit logs.
- `musyawarah.manage`: CRUD access to Musyawarah events and location configuration.
- `participant.manage`: CRUD & verification access to delegate participants.
- `candidate.manage`: CRUD, document review, and publication control for candidates.
- `attendance.manage`: QR scanning & manual check-in capability.
- `voting.manage`: Opening, pausing, and closing election voting sessions.
- `website.manage`: Editing CMS identity, hero, announcements, guidelines, and footer.
