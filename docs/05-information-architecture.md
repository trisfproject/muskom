# Information Architecture (IA)

Bagaimana informasi dikelompokkan dan disajikan kepada pengguna dalam sistem MUSKOM.

## Struktur Navigasi Utama (Global Navigation)

### 1. Peserta (Front-End Portal)
- **Beranda (Dashboard)**: Ringkasan Musyawarah aktif, status presensi.
- **Agenda**: Jadwal acara, waktu sesi sidang.
- **Voting Room**: Area untuk memberikan suara (hanya aktif saat sesi dibuka).
- **Perpustakaan Dokumen**: Kumpulan materi, AD/ART, dan hasil keputusan.
- **Profil**: Pengaturan akun, ganti password, tiket/QR Code presensi.

### 2. Panitia / Admin (Back-Office Dashboard)
- **Dashboard**: Statistik umum, persentase kehadiran, jumlah user aktif.
- **Manajemen Acara**:
  - Daftar Acara
  - Sesi / Pleno
- **Manajemen Pengguna**:
  - Daftar Peserta (Import CSV, Verifikasi, Hak Suara)
  - Daftar Panitia / Role Management
- **Manajemen Presensi**: Check-in manual / Scanner, Live Kuorum.
- **Manajemen Voting**:
  - Pembuatan Kandidat / Opsi
  - Kontrol Voting (Start, Stop, Pause)
  - Hasil Voting (Report & Export)
- **Manajemen Dokumen**: Upload file, kategori file.
- **Pengaturan Sistem**: Konfigurasi global (Nama Organisasi, Logo, Parameter SMTP).
