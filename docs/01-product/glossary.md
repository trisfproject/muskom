# Domain Glossary

- **Musyawarah:** The primary event/convention entity representing a institutional assembly (e.g. Musyawarah Komunitas 2026).
- **Participant (Peserta):** A registered delegate representing an institution, company, or branch with assigned voting rights.
- **Candidate (Bakal Calon / Calon):** A verified individual standing for election within a Musyawarah voting session.
- **Quorum (Kuorum):** The minimum number of verified, checked-in participants required for decisions or elections to be legally valid.
- **Verification (Verifikasi):** Administrative process of reviewing a registrant's details and approving them as an official participant (`Pending` -> `Verified` or `Rejected`).
- **Check-In (Presensi):** Recording a delegate's physical/virtual presence at the convention via QR code scanning.
- **Voting Session:** A timed session opened by administrators during which verified checked-in delegates cast secret votes.
- **Audit Trail:** Asynchronous logging of all system actions, status updates, logins, and configurations.
